- ✅ `deploy_web.sh` - Web deployment script (adapted from attendant app)

  - Provides deployment instructions

## How It Works

### Web Platform
- Uses `WebDatabase` which leverages SQL.js (WebAssembly)
- Database stored in browser's IndexedDB
- Full offline support on web

### Mobile Platform
- Uses `NativeDatabase` with SQLite
- Database stored in app's documents directory
- Full offline support on mobile

### Platform Detection
- Automatic platform detection via conditional imports
- `drift_database_connection.dart` selects the appropriate connection based on platform

## Usage Example

```dart
import 'package:dodomaapp/src/data/drift_database.dart';

// Initialize database
final db = AppDatabase();

// Insert data
await db.into(db.students).insert(StudentsCompanion(
  id: Value(1),
  firstName: Value('John'),
  lastName: Value('Doe'),
  // ... other fields
));

// Query data
final students = await db.select(db.students).get();
```

## Notes

- Drift works on both web and mobile platforms
- No need for platform-specific database code in your business logic
- Type-safe database operations
- Better performance and features compared to sqflite
